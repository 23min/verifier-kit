# verifier-kit devcontainer

Generated by devcontainer-kit (`gh:23min/devcontainer-kit`, private) — the house devcontainer standard
(its `STANDARD.md` has the reasoning). The answers that produced this setup are in
`.copier-answers.yml` at the repo root.

## What's inside

| Tool | How | Version |
|---|---|---|
| gh, ripgrep, jq, sqlite3, tmux, build-essential | apt (house section) | Ubuntu 24.04 |
| uv | Astral's install script | latest (weekly) |
| Claude Code | native installer | latest (updated at every start) |
| Codex | standalone installer into the shared `~/.codex` | latest (checked at every start) |
| Personal guidance | the host's `~/.guidance`, mounted; `initialize.sh` runs its `build` | the host checkout; `git -C ~/.guidance pull` updates it |
| Go | `COPY --from=golang` | latest; `toolchain` in `go.mod` pins |
| Erlang/OTP, Elixir | elixir-lang.org `install.sh` | latest; `.tool-versions` pins |

**Versions.** Everything installs its latest (Node, .NET: latest LTS). To pin, use the language's
own version file; the pin is applied when the container is created. The image's tool layers
refresh at most once a week (`initialize.sh` bumps `.devcontainer/.refresh` and re-pulls the
upstream images).

## What survives a rebuild

- **The repo** — mounted from the host at `/workspaces/verifier-kit` (only this repo).
- **Shared host state** — `~/.claude`, `~/.config/gh`, `~/.guidance` (personal guidance), and `~/.claude-linux/plugins` /
  `~/.codex-linux` (Linux-only state), through `/tmp/.verifier-kit-*` links that
  `initialize.sh` creates on the host.
- **Package caches** — named `devkit-cache-*` volumes, shared by every kit container.

Everything else (venv, installed tools) is rebuilt by the image and `post-create.sh`.

## Files

| File | Owner | Runs |
|---|---|---|
| `devcontainer.json`, `Dockerfile`, `devkit.conf` | kit (generated) | — |
| `initialize.sh` | kit | on the host, before every build/start |
| `post-create.sh` | kit | in the container, once after create |
| `post-start.sh` | kit | in the container, every start |
| `project/*.sh` | **this repo** | after the kit script of the same name; `project/image.sh` as the last image layer |

Kit files are replaced by `uvx copier update`; put project-specific steps in `project/` (never
overwritten). Change an answer with `uvx copier update --data <key>=<value>`.
